SHARED PATTERN USED BY EVERY NEW AI ENDPOINT
================================================================================
- aiConfigured() -> 503 when no ANTHROPIC_API_KEY.
- enforceAiLimit(userId, '<kind>') -> 429 (AiLimitError) on burst/monthly cap.
- 502 on any other Claude/parse failure.
- Parsers: askClaude(prompt, SYSTEM) -> extractJson() -> validate each action ->
  apply via the EXISTING workspace services (never raw SQL) -> return refreshed
  data + applied[]/skipped[] + a one-line reply. Unresolvable actions are SKIPPED
  (never half-applied). Most parsers cap at ~25 actions.
- "Brief me" uses ai/brief.ts generateBrief(userId, kind, system, data), which
  enforces the AI limit internally; UI reuses components/AiBrief.tsx
  (useAiBrief hook + BriefButton/BriefCard/BriefError).

New ai_usage "kind" strings introduced (each shows up in the ai_usage table):
  finance_command, kia_command, wealth_command, trade_log, studies_quiz,
  news_draft, kia_brief, trades_brief. (Plus existing: ask, kia, studies_tutor,
  analyze, news_brief, *_brief.)

FEATURE 9 — GLOBAL "ASK CLAUDE" PANEL CAN TAKE ACTIONS  (commit 7600d74)
================================================================================
The always-on Ask Claude side panel now APPLIES add/log/set instructions (not
just answers) in finance, wealth, kia, and trading. A message that reads like an
action is routed to that workspace's parser; the panel shows what it did (and any
skipped items). Non-action messages, or ones that resolve to nothing, fall back
to a normal chat answer.
  USER CHOSE: "Yes, let it act" (offered Yes / answers-only / act-but-confirm).

Backend:
  - POST /api/ai/act  { workspace, message }  (requireAuth)
    Enforces the SAME per-workspace access as each command bar:
      canAccessWorkspace(roles, ws) + isWorkspaceReadOnly(roles, ws) checks,
      then enforceAiLimit with that workspace's kind. Dispatches to
      runFinanceCommand / runWealthCommand / runKiaCommand / runTradeCommand.
    Verified via app.inject: finance action applies (200, 1 applied); a
    finance-only user is blocked from trading (403).
Web:
  - api.aiAct(workspace, message). AskClaudePanel.tsx detects action intent
    (verb regex: add/log/set/create/new/record/sold/buy/long/short/...), routes
    to /act with chat fallback, adds action examples to per-workspace suggestions.
  - LIMITATION (noted to user): the underlying screen does not auto-refresh after
    a panel action; the confirmation appears in the panel and the screen updates
    on next load/navigation. The panel reply tells the user to refresh.
