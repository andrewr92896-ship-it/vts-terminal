2) WHAT'S ALREADY BUILT (do NOT rebuild) — the Claude foundation
------------------------------------------------------------
All AI goes through ONE backend module and ONE guard. Reuse them.

- apps/api/src/ai/claude.ts
    aiConfigured() -> bool (false when no ANTHROPIC_API_KEY)
    askClaude(prompt, system?) -> string         (Sonnet, single-shot)
    chatClaude(messages[], system?) -> string     (Sonnet, multi-turn)
    extractJson(raw) -> unknown|null              (strip fences, parse first {...})
    analyzeTradeScreenshot(...)                    (Opus 4.8 vision)

- apps/api/src/ai/usage.ts  (USAGE GUARDRAILS — every AI route must use this)
    enforceAiLimit(userId, kind) -> throws AiLimitError on burst/monthly cap, else
      records the call. Per-minute in-memory limit + durable monthly cap from the
      ai_usage table (per Eastern-Time month). Config: AI_MONTHLY_LIMIT (def 1000),
      AI_RATE_PER_MIN (def 15).
    getAiUsage(userId) -> { used, limit, remaining }
    Route pattern (COPY THIS for every new AI endpoint):
        if (!aiConfigured()) return reply.code(503).send({ error: 'AI is not configured (no API key set)' });
        try {
          await enforceAiLimit(userId, '<kind>');
          ... call Claude ...
        } catch (err) {
          if (err instanceof AiLimitError) return reply.code(429).send({ error: err.message });
          return reply.code(502).send({ error: ... });
        }

- apps/api/src/ai/brief.ts -> generateBrief(userId, kind, system, data) for the
  "Brief me" dashboard summaries.

- apps/web/src/components/AiBrief.tsx -> useAiBrief(fetcher) hook + BriefButton /
  BriefCard / BriefError. (Reusable "✨ Brief me" UI.)

3) IMMEDIATE TASK (A): FINANCE NATURAL-LANGUAGE "ADD THINGS" PARSER
------------------------------------------------------------
GOAL: On the Personal Finance section, a Claude-powered input where Andrew types
plain English and it logs the right thing — just like the Kia quick-log. Examples
he should be able to type:
  - "Add a $120 phone bill on the 15th"            -> expense
  - "Add Netflix $18 on the 3rd, subscriptions"     -> expense w/ category
  - "Add my car worth 18000 as an asset"            -> net-worth asset
  - "Add 9500 student loan as a liability"          -> net-worth liability
  - "Switch FTP to funded at 80%" (optional)        -> settings update
  - Multiple in one line, separated by "·"/"and".

DESIGN (mirror apps/api/src/kia/dealParser.ts + apps/api/src/todo/command.ts):
  Backend service: apps/api/src/finance/parser.ts  ->  runFinanceCommand(userId, note)
    - aiConfigured() handled in the route (503).
    - enforceAiLimit(userId, 'finance_command') in the route.
    - askClaude(prompt, SYSTEM) with a system prompt instructing STRICT JSON:
        { "actions": [
            {"type":"expense","label":"...","amount":120,"dayOfMonth":15,"category":"..."},
            {"type":"networth","label":"...","amount":18000,"kind":"asset"|"liability"},
            {"type":"settings","ftpPhase":"funded","ftpPayoutPct":80}   // optional/last
          ],
          "reply":"<one short sentence>" }
    - extractJson(); validate each action; apply via the EXISTING finance services
      (do NOT write SQL directly):
        addExpense(userId, { label, amount, dayOfMonth, category? })   // dayOfMonth 1..31
        addNetWorth(userId, { label, amount, kind })                    // kind: 'asset'|'liability'
        updateSettings(userId, { ftpPhase?, ftpDivisor?, ftpPayoutPct? })
      (signatures in apps/api/src/finance/service.ts; NET_WORTH_KINDS=['asset','liability'],
       FTP_PHASES=['testing','funded'].)
    - Coerce "$1,200" style strings to numbers (see num() in dealParser.ts).
    - If an action can't be resolved (e.g. missing amount), SKIP it and explain;
      don't half-apply. Return { overview/expenses/networth refreshed, applied[],
      skipped[], reply }. Cap at ~25 actions.
  Route: POST /api/finance/command  (preHandler requireWorkspace('finance'))
    - 503 when unconfigured, 429 on AiLimitError, 502 otherwise.
  Frontend: add a "Quick add (Sonnet)" command bar — simplest place is the top of
    Personal Finance (apps/web/src/workspaces/finance/FinanceOverview.tsx), or the
    Expenses screen. Mirror the Kia quick-log UI (KiaDashboard.tsx "Quick log"
    block): an input + button, shows Claude's confirmation line + applied/skipped,
    refreshes data on success, surfaces 503/limit messages. Add api client method

    const realFetch = globalThis.fetch;
    globalThis.fetch = (async (url, init) => {
      if (String(url).includes('/v1/messages')) {
        const body = { id:'m', type:'message', role:'assistant', model:'claude-sonnet-4-6',
          content:[{type:'text', text: JSON.stringify(nextJson)}], stop_reason:'end_turn',
          usage:{input_tokens:1,output_tokens:1} };
        return new Response(JSON.stringify(body), { status:200, headers:{'content-type':'application/json'} });
      }
      return realFetch(url, init);
    }) as typeof fetch;
