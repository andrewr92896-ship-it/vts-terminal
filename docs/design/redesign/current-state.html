3 · Trade card — the signature component

workspaces/trading/TradeCard.tsx. Renders on the Live Wall, Trade Log, Trade History, Trade Desk and the funded book. It does not import the token set at all — every colour below is a local literal that near-misses a token. Note the rule the terminal follows everywhere: a position always shows when it opened, and once closed, when it closed.

4 · Buttons

One gold action per view; everything secondary is a ghost. Note the primary button is teal inside Investments and gold in the shell — the primary colour currently follows the workspace, which is part of why the app reads inconsistent.

5 · Form controls

Every text input is floored at 16px on touch devices site-wide so iOS never zooms on focus. Do not design a smaller mobile input.

6 · Chips, tags and tier marks

A star means Premium (#EBCB74), a gem means Max (#B9F2FF) — terminal-wide, in the sidebar, the tile picker and the channel rail alike. Provenance tags are not decoration: a portfolio priced live is a different object from one priced off a figure typed three months ago, and the screens must never let those look the same.

13 · Type
