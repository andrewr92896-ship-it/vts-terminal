Disclaimer

Worth adding once the terminal is public and paid.

Vitalis Trading Systems provides informational tools only and does not provide investment advice. Nothing in this message is a recommendation to buy or sell any instrument.

Paste this under the signature you chose. It matches the "informational only, not investment advice" wording already used across the terminal, so email and app say the same thing. Not legal advice — worth running past the attorney alongside the rest of the launch review.

Installing it

Gmail
Settings → See all settings → General → Signature → Create new. Paste with Ctrl/Cmd+V, then Save Changes at the bottom of the page.
Outlook web
Settings → Mail → Compose and reply → Email signature. Paste and save.
Outlook desktop
File → Options → Mail → Signatures. Paste into the edit box. Outlook rewrites some styling; check the spacing on a test message to yourself.
Apple Mail
Mail → Settings → Signatures. Untick "Always match my default message font" first, or it will strip the colours.

Send yourself a test first. Mail clients each rewrite HTML a little differently, and a signature that looks right in the settings box can still land wrong.
